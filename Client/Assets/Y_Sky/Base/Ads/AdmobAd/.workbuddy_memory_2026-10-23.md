### 技术要点

- **开屏广告特点**：
  - 使用 Google Mobile Ads SDK 的 `AppOpenAd` 类
  - 适用场景：冷启动、应用从后台恢复、场景切换
  - 展示时机：Load 成功后立即可展示（与插屏/激励类似）

- **竞价价格来源**：
  - 首次展示：强制使用 AdMob（价格未知，eCPM = 0）
  - 后续展示：使用缓存的上一次展示 eCPM 参与竞价

### 使用指南

在 Unity Inspector 的 `SkyGameConfigData.asset` 中填写：
- **开屏广告位**（`splashUnitIds`）：多个广告位用逗号分隔
  - 示例：`ca-app-pub-xxx/111,ca-app-pub-xxx/222`

运行逻辑：
- **首次运行**：AdMob 无开屏历史 eCPM → 强制展示 AdMob → 记录 eCPM
- **后续运行**：AdMob 使用缓存价格与 TopOn 竞价 → 展示最高价者 → 更新缓存

### 测试要点

1. **冷启动测试**：首次运行时开屏是否强制展示 AdMob
2. **竞价测试**：后续运行时是否正确比较 AdMob 与 TopOn 的 eCPM
3. **价格更新**：每次展示后缓存是否正确更新
4. **多广告位**：配置多个开屏广告位时是否正确轮换
